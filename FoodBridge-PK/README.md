# FoodBridge PK — Green Student Edition

A clean, responsive, beginner-friendly frontend concept for a community food-sharing project.

## Technologies
- HTML5 for page structure and content
- CSS3 for custom design and responsive styling
- Bootstrap 5 for grid, spacing and mobile navigation
- Basic JavaScript DOM only: `getElementById()`, `addEventListener()`, `value`, `textContent`, and simple `if/else`

## Pages
- `index.html` — Homepage, how it works and featured food cards
- `explore.html` — Six static sample food listings
- `food-details.html` — Sample food information and a demo request message
- `add-food.html` — Basic food listing form and preview message

## Teammate pages
Donor Dashboard, Receiver Dashboard and Admin Dashboard navigation links intentionally remain `href="#"` for the teammate to build and connect later.

## Run the project
1. Extract the ZIP folder.
2. Open `index.html` in a browser.
3. Internet is required for Bootstrap CDN, Google Fonts and the responsive Bootstrap navigation menu.

## Important project limitation
This is a frontend classroom demonstration. It has no backend, authentication, database, permanent storage or real donation requests. Food cards are static examples. The form and request button only show DOM-based messages. Always verify food freshness, ingredients, allergens, storage and pickup arrangements in a real food-sharing situation.
